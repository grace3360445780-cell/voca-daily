# 보카 데일리

토익 단어 Day 1~30을 카드로 외우고 자동 테스트로 확인하는 웹앱입니다. 서버 없이 동작하고, 기록은 각 기기의 브라우저에 저장됩니다.

- 단어: 기본 2,078개, 800점 2,033개, 900점 954개 (모두 5,065개)
- 카드 학습: 다시 / 어려움 / 알맞음 / 쉬움으로 평가하면 다음 복습 날짜가 자동으로 정해집니다.
- 테스트: 뜻 고르기, 단어 고르기, 철자 쓰기, 듣고 고르기 문제가 단어 목록에서 자동으로 만들어집니다.
- 노트: 오답, 별표, 어려운 단어를 모아 다시 볼 수 있습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 예: `voca-daily`, 공개(Public).
2. 저장소 화면에서 **Add file → Upload files**를 누릅니다.
3. 이 폴더의 파일을 모두 끌어다 놓고 **Commit changes**를 누릅니다.
   - index.html, styles.css, app.js, words.js, extra.js, jua-sub.woff2, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png
4. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 정하고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<아이디>.github.io/voca-daily/` 주소로 열립니다.

## 휴대폰에 설치하기

- 안드로이드(크롬): 주소를 열고 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**.
- 아이폰(사파리): 주소를 열고 공유 버튼 → **홈 화면에 추가**.

한 번 열어 두면 인터넷 없이도 동작합니다.

## 파일을 고친 뒤

`sw.js` 맨 위의 `VERSION` 숫자를 올려서 함께 올려야 휴대폰에 새 버전이 반영됩니다. 예: `voca-daily-v1.0.0` → `voca-daily-v1.0.1`.
앱을 한 번 닫았다 다시 열면 새 버전으로 바뀝니다.

## 글꼴

제목과 버튼에 쓴 글꼴은 Woowahan Brothers의 Jua(SIL Open Font License 1.1)입니다. 앱에 쓰는 글자만 남긴 파일(jua-sub.woff2)을 넣었습니다.

## 기록 백업

기록은 기기마다 따로 저장됩니다. 설정(톱니바퀴) → **파일로 저장**으로 백업하고, 다른 기기에서 **파일 불러오기**로 옮기세요.
앱을 지우거나 브라우저 데이터를 지우면 기록도 사라지므로 2주에 한 번은 백업하세요.
